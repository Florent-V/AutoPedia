# 4. Collection

La page Collection affiche **tout le catalogue** :

- les cartes possédées en couleur, avec le nombre d'exemplaires (×2, ×3…) ;
- les cartes manquantes en **silhouette grise** : le nom reste visible, mais pas la photo. Le joueur sait ainsi ce qu'il lui reste à trouver.

## Progression

En haut de la page :

- le total « cartes possédées / cartes du catalogue », le pourcentage de complétion et les points de collection ;
- une **jauge par rareté** (par exemple « Rare 12/450 »). Toucher une jauge filtre la collection sur cette rareté.

## Filtres et tri

| Filtre | Valeurs |
| --- | --- |
| Recherche | Nom du modèle ou de la marque |
| Constructeur | Liste des marques, avec la progression pour chacune (« Ferrari (3/41) ») |
| Catégorie | Route et course, voitures de route, voitures de course 🏁 |
| Possession | Toutes, possédées, manquantes |
| Tri | Rareté (par défaut), nom, année, ajout au catalogue |

Sur téléphone, les filtres sont repliés derrière un bouton « Filtres (n) » qui indique le nombre de filtres actifs, et les jauges de rareté défilent horizontalement.

Les filtres sont repris dans l'adresse de la page : on peut partager ou mettre en favori une vue filtrée.

## Fiche d'une carte

Toucher une carte ouvre sa fiche :

- la carte en grand, interactive (inclinaison, reflets holographiques) ;
- la marque, le pays, les années de production, la catégorie (route ou course), la masse, la longueur, la puissance, la vitesse et le nombre d'exemplaires ;
- pour une carte possédée : le **résumé Wikipédia**, le lien vers l'article, les **crédits de la photo** (auteur, licence, lien vers Commons) et le bouton **« Proposer à l'échange »**, qui ouvre la bourse avec la carte présélectionnée ;
- pour une carte manquante : une invitation à ouvrir des boosters. Le résumé reste caché pour garder la surprise.
